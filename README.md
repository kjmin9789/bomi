# 보미 (Bomi)

하나만 해도 좋아요. 작은 행동을 기록하고 실천한 테마 수를 꽃으로 확인하는 로컬 웹앱입니다.

## 실행

Node.js 18 이상에서 외부 패키지 설치 없이 실행합니다.

```sh
npm start
```

브라우저에서 http://127.0.0.1:4173 을 엽니다.

```sh
npm test
```

## 기능

- 이 컴퓨터의 Codex에 개인 프로젝트 작업 정리를 요청하고 초안 확인 후 기록
- 재테크·커리어·건강 행동 기록, 수정·삭제와 날짜별 탐색
- 하루에 실천한 서로 다른 테마 수에 따른 0~3단계 꽃과 월간 캘린더
- 작은 행동 제안, 완료 피드백, 미래 문장과 주간 회고
- 기록 보관함, JSON 백업·가져오기
- 실제 저장 데이터와 분리된 가상 예시 모드
- 앱이 열려 있는 동안 확인하는 알림

## 데이터와 공개 범위

이 저장소에는 앱 코드·테스트·UI 이미지와 일반적인 가상 예시만 포함됩니다. 실제 개인 기록, 미래 문장, 회고, 백업 파일, 기획 대화와 개인 문서는 포함하지 않습니다.

확인한 기록은 해당 브라우저의 localStorage에 저장됩니다. GitHub에 동기화하지 않습니다. Codex 정리 요청·연결 정보·근거를 포함한 결과 초안은 로컬 `.data/codex/`에 보관되며 공개 저장소와 정적 파일 제공 대상에서 제외됩니다. 브라우저 데이터를 삭제하면 기록이 사라질 수 있으므로 설정에서 백업하세요. 백업 파일을 저장소에 추가하지 마세요.

보미 로그인·기기 간 동기화·앱이 닫힌 상태의 푸시는 아직 지원하지 않습니다. 날짜 기준은 Asia/Seoul입니다.

## Codex로 한 일 가져오기

macOS의 Codex 앱과 로컬 보미 서버가 실행 중이어야 합니다. 홈의 **오늘 한 일 가져오기**는 연결된 기존 Codex 채팅에 요청을 보냅니다. Codex가 이 컴퓨터의 개인 프로젝트에서 선택 날짜(한국시간)에 확인된 완료 내역을 정리하고 테마를 제안합니다. 캘린더에서 과거 날짜를 선택한 뒤 **이날 한 일 가져오기**를 누르면 그날의 대화 내역을 같은 방식으로 확인합니다. 회사·범위 불명확한 작업은 제외하도록 요청합니다. 분류는 AI 제안이므로 결과와 근거를 확인해야 합니다. 확인한 항목만 기록과 꽃에 반영됩니다.

Codex 채팅에서 `npm start`로 처음 실행하면 해당 채팅 ID를 로컬에 저장합니다. 연결이 없거나 바꾸려면 **설정 → 이 컴퓨터의 Codex 연결 설정**에서 기존 채팅 ID를 입력하세요. `BOMI_CODEX_THREAD_ID`로 초기 연결 대상을 지정할 수도 있습니다. 다른 컴퓨터에서는 그 기기의 서버와 Codex를 별도로 연결해야 하며, 원격 웹사이트만으로 방문자 컴퓨터의 Codex를 제어하지 않습니다.

별도 AI API 키는 사용하지 않습니다. 정리는 연결된 Codex의 로그인과 사용량을 사용하며 해당 서비스에서 처리됩니다. Codex가 다른 작업 중이면 대기할 수 있습니다. 요청이 접수된 것과 완료된 것을 구분하며 결과 파일이 검증된 뒤에만 초안을 표시합니다. 전달이 불명확하면 자동 재전송하지 않습니다. `이 요청 종료하기`는 보미의 대기만 종료하고 Codex 작업을 중단하지 않습니다.

같은 날짜·같은 원본 채팅은 하나의 기록으로 합쳐집니다. 다시 가져오면 새 초안을 확인한 뒤 해당 기록을 갱신하고, 이전에 보관한 상태는 유지합니다. `직접 기록하기`로 수동 입력도 할 수 있습니다. `.data/`에는 개인 작업 요약이 있으므로 공개하거나 Git에 추가하지 마세요.

## 개발

`app/`은 HTML/CSS/JavaScript, `server.mjs`는 허용된 정적 파일과 Codex 연결 API를 제공하는 로컬 서버, `codex-bridge.mjs`는 로컬 Codex 요청·초안 검증, `tests/`는 모델·연결·API 검증입니다. 색상은 CSS 토큰을 사용합니다. 글자는 최소 14px로 유지합니다.

변경은 작업 브랜치와 PR로 제안하고, 저장소 소유자가 검토한 뒤 Squash and merge 합니다.
