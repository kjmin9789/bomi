# 보미 (Bomi)

하나만 해도 좋아요. 작은 행동을 기록하고 실천한 테마 수를 꽃으로 확인하는 로컬 웹앱입니다.

## 실행

Node.js 18 이상에서 외부 패키지 설치 없이 실행합니다.

```sh
npm start
```

브라우저에서 http://127.0.0.1:4173 을 엽니다.

```sh
npm test
```

## 기능

- 재테크·커리어·건강 행동 기록, 수정·삭제와 날짜별 탐색
- 하루에 실천한 서로 다른 테마 수에 따른 0~3단계 꽃과 월간 캘린더
- 작은 행동 제안, 완료 피드백, 미래 문장과 주간 회고
- 기록 보관함, JSON 백업·가져오기
- 실제 저장 데이터와 분리된 가상 예시 모드
- 앱이 열려 있는 동안 확인하는 알림

## 데이터와 공개 범위

이 저장소에는 앱 코드·테스트·UI 이미지와 일반적인 가상 예시만 포함됩니다. 실제 개인 기록, 미래 문장, 회고, 백업 파일, 기획 대화와 개인 문서는 포함하지 않습니다.

입력한 내용은 해당 브라우저의 localStorage에 저장됩니다. 서버로 전송하거나 GitHub에 동기화하지 않습니다. 브라우저 데이터를 삭제하면 기록이 사라질 수 있으므로 설정에서 백업하세요. 백업 파일을 저장소에 추가하지 마세요.

로그인·기기 간 동기화·AI 분석·앱이 닫힌 상태의 푸시는 아직 지원하지 않습니다. 날짜 기준은 Asia/Seoul입니다.

## 개발

`app/`은 HTML/CSS/JavaScript, `server.mjs`는 허용된 정적 파일만 제공하는 로컬 서버, `tests/`는 모델 검증입니다. 색상은 CSS 토큰을 사용합니다. 글자는 최소 14px로 유지합니다.

변경은 작업 브랜치와 PR로 제안하고, 저장소 소유자가 검토한 뒤 Squash and merge 합니다.
