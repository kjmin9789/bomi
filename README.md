# 보미 (Bomi)

하나만 해도 좋아요. 작은 행동을 기록하고 실천한 테마 수를 꽃으로 확인하는 로컬 웹앱입니다.

## 실행

로컬 버전은 Node.js 22 이상에서 실행합니다. Cloudflare 개발·검증에는 먼저 `npm ci`로 의존성을 설치합니다.

```sh
npm start
```

브라우저에서 http://127.0.0.1:4173 을 엽니다.

```sh
npm test
```

## 기능

- 이 컴퓨터의 Codex에 개인 프로젝트 작업 정리를 요청하고 초안 확인 후 기록
- 재테크·커리어·건강 행동 기록, 수정·삭제와 날짜별 탐색
- 하루에 실천한 서로 다른 테마 수에 따른 0~3단계 꽃과 월간 캘린더
- 작은 행동 제안, 완료 피드백, 미래 문장과 주간 회고
- 기록 보관함, JSON 백업·가져오기
- 실제 저장 데이터와 분리된 가상 예시 모드
- 앱이 열려 있는 동안 확인하는 알림

## 데이터와 공개 범위

이 저장소에는 앱 코드·테스트·UI 이미지와 일반적인 가상 예시만 포함됩니다. 실제 개인 기록, 미래 문장, 회고, 백업 파일, 기획 대화와 개인 문서는 포함하지 않습니다.

확인한 기록은 해당 브라우저의 localStorage에 저장됩니다. GitHub에 동기화하지 않습니다. Codex 정리 요청·연결 정보·근거를 포함한 결과 초안은 로컬 `.data/codex/`에 보관되며 공개 저장소와 정적 파일 제공 대상에서 제외됩니다. 브라우저 데이터를 삭제하면 기록이 사라질 수 있으므로 설정에서 백업하세요. 백업 파일을 저장소에 추가하지 마세요.

보미 로그인·기기 간 동기화·앱이 닫힌 상태의 푸시는 아직 지원하지 않습니다. 날짜 기준은 Asia/Seoul입니다.

## Codex로 한 일 가져오기

macOS의 Codex 앱과 로컬 보미 서버가 실행 중이어야 합니다. 홈의 **오늘 한 일 가져오기**는 연결된 기존 Codex 채팅에 요청을 보냅니다. Codex가 이 컴퓨터의 개인 프로젝트에서 선택 날짜(한국시간)에 확인된 완료 내역을 정리하고 테마를 제안합니다. 캘린더에서 과거 날짜를 선택한 뒤 **이날 한 일 가져오기**를 누르면 그날의 대화 내역을 같은 방식으로 확인합니다. 회사·범위 불명확한 작업은 제외하도록 요청합니다. 분류는 AI 제안이므로 결과와 근거를 확인해야 합니다. 확인한 항목만 기록과 꽃에 반영됩니다.

Codex 채팅에서 `npm start`로 처음 실행하면 해당 채팅 ID를 로컬에 저장합니다. 연결이 없거나 바꾸려면 **설정 → 이 컴퓨터의 Codex 연결 설정**에서 기존 채팅 ID를 입력하세요. `BOMI_CODEX_THREAD_ID`로 초기 연결 대상을 지정할 수도 있습니다. 다른 컴퓨터에서는 그 기기의 서버와 Codex를 별도로 연결해야 하며, 원격 웹사이트만으로 방문자 컴퓨터의 Codex를 제어하지 않습니다.

별도 AI API 키는 사용하지 않습니다. 정리는 연결된 Codex의 로그인과 사용량을 사용하며 해당 서비스에서 처리됩니다. Codex가 다른 작업 중이면 대기할 수 있습니다. 요청이 접수된 것과 완료된 것을 구분하며 결과 파일이 검증된 뒤에만 초안을 표시합니다. 전달이 불명확하면 자동 재전송하지 않습니다. `이 요청 종료하기`는 보미의 대기만 종료하고 Codex 작업을 중단하지 않습니다.

가져온 초안은 작업 내용과 목적별 묶음 아래에 구체적인 완료 행동을 보여줍니다. 채팅이나 프로젝트가 달라도 관련된 작업은 같은 묶음으로 정리하며, 묶음 이름을 확인·수정할 수 있습니다. 확인 후 기록 목록과 백업에도 묶음을 유지합니다. 이전 초안은 기타 작업으로 표시됩니다.

같은 날짜·같은 원본 채팅은 하나의 기록으로 합쳐집니다. 다시 가져오면 새 초안을 확인한 뒤 해당 기록을 갱신하고, 이전에 보관한 상태는 유지합니다. `직접 기록하기`로 수동 입력도 할 수 있습니다. `.data/`에는 개인 작업 요약이 있으므로 공개하거나 Git에 추가하지 마세요.

## 개발

`app/`은 HTML/CSS/JavaScript, `server.mjs`는 허용된 정적 파일과 Codex 연결 API를 제공하는 로컬 서버, `codex-bridge.mjs`는 로컬 Codex 요청·초안 검증, `tests/`는 모델·연결·API 검증입니다. 색상은 CSS 토큰을 사용합니다. 글자는 최소 14px로 유지합니다.

변경은 작업 브랜치와 PR로 제안하고, 저장소 소유자가 검토한 뒤 Squash and merge 합니다.

## Cloudflare 버전

Workers·D1·Cloudflare Access를 사용하는 개인용 구성을 추가했습니다.
허용 이메일 한 개로 로그인하고 여러 기기에서 기록을 조회·저장할 수 있습니다.
서버 저장 전 로컬 복구 자료를 남기며, 동시 수정은 충돌로 알려 다른 기기 기록을 덮어쓰지 않습니다.

알림 시각과 기기 권한을 켜면 앱이 닫혀 있어도 웹 푸시를 보낼 수 있습니다.
이미 기록했거나 쉬어가는 날에는 보내지 않습니다.
실제 사용에는 Cloudflare 배포·Access 설정·알림 키 등록·기기별 수신 검증이 필요합니다.
`npm start`의 기존 로컬 버전은 별도로 유지됩니다.

설정, 무료 플랜 유지, 인증 검증 및 기존 기록 이관 방법은 [Cloudflare 배포 안내](cloud/README.md)를 참고하세요.
원격 버전의 Codex 자동 수집은 연결하지 않았으며, 로컬에서 확인한 기록을 JSON 백업으로 옮길 수 있습니다.

## 반복 질문

설정의 **반복해서 물어보기**에서 질문, 요일, 한국시간을 저장하고 켜거나 끌 수 있습니다. 오늘 화면에서 했는지 답하거나 건너뛸 수 있고, 취침 질문은 지난밤 누운 날짜와 시각을 받아 다음 날 기준 시각 전인지 표시합니다. 기준 시각과 같으면 ‘이후’로 표시합니다. 답변은 날짜별로 조회·수정하고 백업에 함께 보관합니다. 답변 자체로 꽃을 채우지 않으며, 테마를 확인한 실제 행동 기록으로 반영합니다.

서로 다른 질문은 개별 알림으로 처리하고 답변한 질문이나 쉬어가는 날은 재촉하지 않습니다. 미응답 질문은 해당 날짜에만 보여주며 다음 날 밀린 질문을 보내지 않습니다. 로컬은 열린 페이지에서만 확인하고 Cloudflare는 기기별 푸시 등록 후 예약 실행에서 확인합니다. 개인 일정 기본값은 공개 코드에 포함하지 않습니다.

## 클라우드 화면에서 이 컴퓨터의 Codex 가져오기

각 컴퓨터에서 Node.js 22 이상과 Codex 앱을 준비하고, 이 버전의 보미 폴더에서 아래를 실행합니다. 주소는 본인의 보미 HTTPS 주소로 바꿉니다.

```sh
npm run bridge -- https://YOUR-BOMI.workers.dev
```

연결 프로그램은 `127.0.0.1:4174`에서 실행되므로 켜둔 터미널을 유지합니다. 클라우드 보미의 **설정 → 이 컴퓨터의 Codex 연결 설정**에 해당 컴퓨터의 채팅 ID를 저장한 뒤 **오늘/이날 한 일 가져오기**를 누릅니다. 최신 데스크톱 Chrome에서 로컬 연결 권한을 요청하면 허용합니다. 회사 정책이 차단한 연결은 우회하지 않습니다.

초안과 근거는 이 컴퓨터에서 읽고, 사용자가 확인한 기록만 기존 클라우드 기록에 추가·갱신합니다. 다른 기기에서는 새로고침하면 볼 수 있습니다. 전체 백업을 교체하지 않으며, 저장에 실패하면 수집 요청을 닫지 않고 브라우저의 전송 대기 자료와 로컬 초안을 보존합니다. 다른 기기가 먼저 저장했으면 복구 안내에 따라 최신 기록을 불러온 뒤 다시 확인합니다.

연결은 실행할 때 지정한 HTTPS 원본 한 곳에만 허용합니다. 사이트 로그인 쿠키나 토큰을 로컬 프로그램으로 전송하지 않습니다. Codex가 사용하는 계정은 컴퓨터마다 달라도 되며, 보미의 저장 계정은 같습니다. 회사 자료 수집은 허용하지 않습니다. 휴대폰은 직접 입력·기록 조회·알림용이며 컴퓨터의 Codex를 원격 실행하지 않습니다.
